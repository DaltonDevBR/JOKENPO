# ✊✋✌️ JOKENPO

Meu primeiro projeto em C publicado no GitHub.

## 📖 Sobre o projeto

Este é um jogo de Jokenpô (Pedra, Papel e Tesoura) desenvolvido em linguagem C. O jogador escolhe uma opção e joga contra o computador, que gera sua escolha aleatoriamente.

## 🚀 Funcionalidades

- Escolha entre Pedra, Papel ou Tesoura
- Jogador contra computador
- Geração aleatória das jogadas
- Exibição do vencedor da rodada
- Ganha quem fizer 5 pontos primeiro.

## 🛠️ Tecnologias Utilizadas

- Linguagem C
- GCC

## ▶️ Como Executar

Compile o programa:

```bash
gcc jokenpo.c -o jokenpo
```

Execute:

```bash
./jokenpo
```
